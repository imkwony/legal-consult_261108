# 설정 안내서

처음 한 번만 하면 됩니다. 순서대로 따라 하세요.

## 준비물
- 구글 계정
- BAZE API 키 (https://docs.factchat.kr/docs/korea-seoul/api-gateway/getting-started/overview)
- 국가법령정보 Open API 인증키(OC) (open.law.go.kr → Open API 사용 신청)
- GitHub 계정

---

## 1. 구글 스프레드시트 준비
1. 상담 기록을 저장할 구글 스프레드시트를 엽니다(새로 만들어도 됩니다).
2. 주소창에서 `/d/`와 `/edit` 사이의 글자를 복사합니다. 이것이 **시트 ID**입니다.
   - 예: `https://docs.google.com/spreadsheets/d/`**`1tuQww...XadQ`**`/edit`
3. 저장용 탭 `상담기록`은 첫 상담을 저장할 때 자동으로 생깁니다.

## 2. Apps Script에 코드 넣기
1. 스프레드시트 메뉴에서 **확장 프로그램 → Apps Script**를 엽니다. 이미 만든 Apps Script 프로젝트가 있으면 그걸 열어도 됩니다.
2. 왼쪽의 `Code.gs`를 열고, 기존 내용을 모두 지운 뒤 이 저장소의 [`apps-script/Code.gs`](../apps-script/Code.gs) 내용을 통째로 붙여넣습니다.
3. 💾 저장을 누릅니다.

## 3. 비밀 키 넣기 (스크립트 속성)
1. Apps Script 왼쪽의 ⚙️ **프로젝트 설정**을 누릅니다.
2. 맨 아래 **스크립트 속성 → 스크립트 속성 추가**에서 아래 세 개를 추가합니다.

   | 속성 | 값 |
   |---|---|
   | `BAZE_API_KEY` | 내 BAZE 키 (설정에서 키를 비워둔 사람은 이 키를 씁니다) |
   | `LAW_OC` | 국가법령정보 OC 키 |
   | `SHEET_ID` | 1단계에서 복사한 시트 ID |

3. **스크립트 속성 저장**을 누릅니다.

> 키는 여기에만 넣으세요. GitHub 저장소나 사이트 코드에는 절대 넣지 않습니다.

## 4. 웹 앱으로 배포
1. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. ⚙️(유형 선택)에서 **웹 앱**을 고릅니다.
3. 다음처럼 설정합니다.
   - 실행 사용자: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포**를 누릅니다. 권한 승인 창이 뜨면 내 계정을 고르고 허용합니다. "Google에서 확인하지 않은 앱" 경고가 나오면 **고급 → (프로젝트 이름)(으)로 이동**을 누릅니다.
5. 끝에 `/exec`로 끝나는 **웹 앱 URL**이 나옵니다. 이 주소를 복사해 두세요.

> 이 주소를 아는 사람은 내 키로 AI를 쓸 수 있습니다. 다른 사람에게 알려주지 마세요.

## 5. GitHub Pages로 사이트 올리기
1. 저장소 https://github.com/imkwony/legal-consult_261108 에 코드를 올립니다(main 브랜치).
2. 저장소의 **Settings → Pages**로 갑니다.
3. Source는 **Deploy from a branch**, Branch는 **main / (root)**로 정하고 Save를 누릅니다.
4. 1~2분 뒤 `https://imkwony.github.io/legal-consult_261108/` 주소로 사이트가 열립니다.

## 6. 웹 앱 주소를 코드에 넣기
4단계의 웹 앱 URL은 사이트 코드 [`js/settings.js`](../js/settings.js)의 `SCRIPT_URL`에 고정되어 있습니다. 새 배포를 만들어 주소가 바뀌었다면 이 값을 고친 뒤 GitHub에 다시 올리세요. "배포 관리 → 새 버전"으로 배포하면 주소는 바뀌지 않습니다.

> ⚠️ 이 주소는 공개 저장소에 그대로 보입니다. 주소를 아는 사람은 "기본 키 사용하기"로 내 BAZE 크레딧을 쓸 수 있고, 저장된 상담 기록도 조회할 수 있습니다.

## 7. 아버지 기기에서 쓰기
1. 사이트를 엽니다. 기본으로 **기본 키 사용하기**가 체크되어 있어서 따로 설정할 것이 없습니다.
2. 본인 BAZE 키를 쓰고 싶으면 **설정**에서 체크를 풀고 키를 입력합니다.
3. **AI 모델**은 설정에서 고를 수 있습니다. **더 많은 모델 불러오기**를 누르면 BAZE의 전체 대화 모델이 나옵니다.
4. 휴대폰에서는 사이트를 연 뒤 **홈 화면에 추가**를 해두면 앱처럼 쓸 수 있습니다.

## 코드를 고쳤을 때 (중요)
`Code.gs`를 수정했다면 **배포 → 배포 관리 → ✏️ 편집 → 버전: 새 버전 → 배포**를 해야 반영됩니다. 이렇게 하면 웹 앱 URL은 바뀌지 않습니다.

## 문제 해결
| 증상 | 해결 |
|---|---|
| "설정의 주소를 확인해 주세요" | `js/settings.js`의 `SCRIPT_URL`이 `/exec`로 끝나는 웹 앱 주소인지(스프레드시트 주소가 아님), 4단계에서 액세스 권한을 **모든 사용자**로 했는지 확인 |
| "알 수 없는 요청: models" | `Code.gs`를 최신으로 붙여넣고 **새 버전**으로 배포 |
| "스크립트 속성에 … 가 없습니다" | 3단계의 속성 이름 철자 확인 (대문자) |
| "BAZE 오류 401" | `BAZE_API_KEY` 값 확인 |
| "BAZE 오류 429" | 잠시 후 다시 시도 (1분에 120회 제한) |
| "저장하지 못했어요" | `SHEET_ID` 확인, 시트 소유 계정과 스크립트 배포 계정이 같은지 확인 |
| 답변이 오래 걸림 | 판례와 법령을 여러 번 찾기 때문에 30초~1분 걸릴 수 있습니다 |
